# 记事本 · 前端重设计需求书（OpenDesign Brief v2）

> 目标：为已存在的 Windows 桌面记事本应用（Tauri 2 + Vue 3）**重新设计前端界面与信息架构**。
> 参考对象：市面上成熟优秀的知识管理与笔记产品（Obsidian / Notion / Bear / 语雀 / Apple 备忘录）。
> 产出：一份像素级精致的单页 HTML 原型（含深浅双主题、完整可交互）。

## 一、产品现状（功能已全部实现，重设计只改界面与信息架构）

现有功能清单（必须全部保留在新设计中）：
1. **多工作目录**：可添加/切换/移除多个笔记文件夹（类似 Obsidian 的库选择器）
2. 纯文件存储：.md 与 .txt 两种格式（文件类型需要可视化区分）
3. 多标签页编辑、自动保存（1 秒防抖）、保存状态指示
4. 编辑/预览/分栏三模式（CodeMirror 编辑器 + Markdown 预览）
5. 语法高亮（Python/JS/JSON/HTML/Shell）、代码块复制、LaTeX 公式（KaTeX）
6. 本地图片插入（复制到 assets/ 并在预览显示）
7. JSON 工具条：格式化 / 校验 / 树状查看
8. 文件夹树、标签（彩色圆点）、星标、置顶
9. 全文搜索（标题/正文/标签，命中高亮）
10. 回收站（恢复/彻底删除）
11. 深浅双主题、无边框窗口、右上角 Windows 窗口控制
12. 纯净编辑模式（隐藏侧栏）、编辑器字体/字号设置、txt 自动换行开关
13. 快捷键：Ctrl+N/S/W/Tab、Esc 退出纯净模式

## 二、设计参考（成熟案例要点）

- **Obsidian**：左侧库切换器 + 文件树；笔记列表与编辑器并排；信息密度高但克制
- **Notion**：侧边栏分层导航（工作区 → 页面树）、卡片化列表、现代留白
- **Bear**：极简三栏、标签体系贯穿、编辑器沉浸感
- **语雀**：知识库 → 文档树 → 编辑器三层结构，中文排版优秀
- **Apple 备忘录**：毛玻璃材质、克制的层级、即时搜索

## 三、新信息架构（核心改动）

```
┌────────────────────────────────────────────────────────────────┐
│ 标题栏：窗口按钮 · 库切换器 ▾ · 搜索 · 新建 · 纯净模式 · 主题 · 设置 │
├──────────────┬──────────────────────┬───────────────────────────┤
│ 侧栏          │ 笔记列表               │ 编辑区（多标签）            │
│ ┌──────────┐ │ 列表头：当前视图+计数    │ ┌ Tab1 ─ Tab2 ─ + ─────┐ │
│ │ 库选择器   │ │ 排序/视图切换（列表/网格）│ │ 格式工具条 · 模式分段控件 │ │
│ │ ▼ 工作    │ │ 卡片：类型徽章·标题·摘要 │ │ CodeMirror / 预览/分栏  │ │
│ │  会议记录  │ │      字数·时间·星标置顶 │ │ JSON 工具条（检测时）    │ │
│ │  项目文档  │ │                      │ └────────────────────────┘ │
│ │  学习     │ │                      │ 状态栏：字数·保存状态·换行开关 │
│ ├──────────┤ │                      │                           │
│ │ 全部笔记   │ │                      │                           │
│ │ 收藏      │ │                      │                           │
│ │ 最近编辑   │ │                      │                           │
│ │ 标签      │ │                      │                           │
│ │ 回收站    │ │                      │                           │
│ └──────────┘ │                      │                           │
└──────────────┴──────────────────────┴───────────────────────────┘
```

### 关键设计点

1. **库切换器（工作目录）**：侧栏顶部，显示当前库名称（文件夹名）+ ▾ 下拉（列出全部库，可切换/添加/移除）——参考 Obsidian 库选择器与 Notion 工作区
2. **侧栏导航分层**：
   - 第一组（智能视图）：全部笔记 / 收藏（星标）/ 最近编辑
   - 第二组（文件夹树）：可展开收起，显示各文件夹笔记数
   - 第三组（标签）：彩色圆点胶囊
   - 底部：回收站 + 折叠按钮
3. **文件类型可视化**：卡片与文件夹行都显示类型徽章（MD 蓝色 / TXT 绿色）
4. **笔记列表增强**：卡片显示类型徽章、标题、摘要、字数、相对时间；列表头显示当前视图名与计数；可选"网格视图"（平铺卡片）
5. **空状态**：无笔记时居中插图 + 主操作按钮；搜索无结果显示"未找到与 XX 相关的内容"
6. **编辑器**：保持分栏/编辑/预览三模式；标签页未保存 ●；JSON 检测时浮现工具条
7. **多库切换动画**：切换工作目录时列表平滑过渡
8. **视觉基调**：延续苹果设计语言（#f5f5f7 浅灰底 / #1d1d1f 墨黑 / #0071e3 苹果蓝，SF Pro 字体栈，毛玻璃，8-12px 圆角），但吸收 Obsidian/Notion 的信息密度与层级清晰度——**比第一版更专业、更紧凑、更像成熟生产力工具，而不是"仿备忘录"**

## 四、必须包含的界面元素（逐一精细设计）

1. 标题栏：库切换器（显示当前库名+下拉箭头）、搜索框、新建（+下拉 md/txt）、纯净模式、主题、设置、右上角 Windows 三键
2. 库选择器下拉：全部库列表（当前库高亮 ✓、切换按钮、移除 ×）、"+ 添加新库"按钮
3. 侧栏三组导航 + 折叠 rail 模式（图标条）
4. 笔记列表：列表/网格视图切换（分段控件）、卡片（类型徽章/标题/摘要/字数/时间/星标/置顶/悬停操作）
5. 多标签编辑区：TabBar、格式工具条、编辑/预览/分栏分段控件、JSON 工具条、状态栏
6. 设置弹窗：主题（浅/深）、编辑器字体（系统字体列表）、字号、库管理、关于
7. 首启欢迎页：选择/创建笔记库
8. 空状态（无笔记/无搜索结果）、toast 提示

## 五、交互与状态

- 全部可交互：库切换、视图切换（列表/网格）、导航过滤、标签页操作、主题切换、模式切换、JSON 树展开、搜索过滤、侧栏折叠
- 示例数据：至少 10 篇中文笔记分布在多个文件夹/标签，含 .md 与 .txt 各若干；JSON 示例笔记一篇；代码块（python/js/json）笔记一篇；LaTeX 公式笔记一篇
- 动画：150-250ms ease，克制

## 六、技术约束

- 纯 HTML + CSS + 原生 JS，单文件或少量文件，不依赖构建工具
- 中文 UI；系统字体栈（PingFang SC / Microsoft YaHei 回退）
- 深浅主题都完整实现
- 4px 基准网格；中英文混排美观

## 七、质量要求

- 第一眼观感：**成熟、专业、高级**——像 Obsidian/Notion 级别的产品质感
- 信息架构清晰：三级导航（库 → 文件夹/视图 → 笔记）不混乱
- 任何元素不突兀，留白与密度平衡
