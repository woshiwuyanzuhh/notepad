# 记事本 · 前端设计需求书（OpenDesign Brief）

> 目标：为一个 Windows 桌面记事本应用（Tauri + Vue 3）设计**苹果风格**的完整前端界面。
> 产出：一份可直接预览的、像素级精致的单页 HTML 原型（prototype），供后续移植为 Vue 组件。

## 一、产品背景

一个**个人本地使用的桌面记事本**。纯本地存储（每篇笔记一个 .md 文件），无需登录、无云同步。
界面语言：简体中文。需要同时支持 **浅色 / 深色** 两套主题。

## 二、设计基调（Apple 设计语言）

- **整体气质**：克制、通透、精致。像 macOS 的「备忘录 (Notes)」与「Pages」的结合体。
- **材质**：半透明毛玻璃（frosted glass / backdrop-blur）、微妙的分层阴影、圆角（8–12px 大圆角）。
- **字体**：系统字体栈（`-apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`），标题用大字重（600–700），正文 14–15px。
- **色彩（浅色）**：背景近白（#F5F5F7 系）、侧栏更白、强调色用苹果蓝（#0071E3）或渐变蓝紫；文字主色 #1D1D1F。
- **色彩（深色）**：背景 #1E1E20 / #2A2A2C 分层、毛玻璃高光、强调色 #0A84FF。
- **动效**：细腻的过渡（150–250ms ease）、悬停微交互、切换标签页的轻滑动。
- **无边框感**：顶部区域融入窗口（自定义标题栏风格，左侧交通灯/窗口按钮占位，居中或左侧标题），避免传统 Windows 灰色边框感。
- **图标**：SF Symbols 风格线条图标（圆角矩形内、细描边 1.5px、圆头端点）。

## 三、布局（三栏，可折叠侧栏）

```
┌────────────────────────────────────────────────────────────────┐
│ 标题栏：窗口按钮 · 应用名「记事本」 · 搜索框 · 主题切换 · 设置    │
├──────────┬─────────────────────┬────────────────────────────────┤
│ 侧栏      │ 笔记列表             │ 编辑区（多标签页 Tab）            │
│ 全部笔记  │ 搜索高亮/筛选        │ ┌─ Tab1 ─ Tab2 ─ + ──────────┐ │
│ 📁 文件夹  │ 笔记卡片（标题、摘要、 │ │ 编辑/预览切换 · 格式工具条    │ │
│   工作    │ 时间、星标、置顶标记） │ │ 正文编辑区（Markdown）        │ │
│   生活    │                    │ │ 代码块高亮 · JSON 工具条      │ │
│ 🏷 标签    │                    │ └─────────────────────────────┘ │
│ 回收站    │                    │ 状态栏：字数 · 保存状态 · 光标位置 │
└──────────┴─────────────────────┴────────────────────────────────┘
```

要求：
- 侧栏可折叠（宽度 200–240px，折叠成窄条图标模式）
- 编辑区支持三种模式：**编辑 / 预览 / 分栏**（用右上角分段控件切换，苹果风）
- 未保存的标签页标题带 ● 圆点

## 四、必须包含的界面元素（逐一精细设计）

1. **启动空状态**：无笔记时显示居中插图（渐变圆 + 线条笔记图标）+「新建笔记」主按钮，苹果式空状态引导。
2. **笔记列表**：卡片式条目，含标题、首行摘要、相对时间（刚刚/3 分钟前/昨天）、星标 ★、置顶 📌 标记；悬停显示操作（星标/删除）；选中态用毛玻璃高亮。
3. **编辑工具栏**：加粗、斜体、标题 H1/H2、列表、引用、代码块、链接、图片——统一为 SF Symbols 风格圆形图标按钮，hover 有浅灰圆底。
4. **Markdown 预览**：排版接近苹果文稿风格——大标题、宽松行距（1.6–1.8）、代码块深色圆角容器（带语言标签小徽章）、引用块左侧竖线、表格细腻描边。
5. **代码块**：深色底（#1E1E1E / #282C34）圆角容器，顶部有语言徽章（如 `python`）+ 复制按钮；**语法高亮**（至少 Python / JavaScript / JSON / HTML / Shell 五种语言配色）。
6. **JSON 工具**：当检测到 JSON 内容时，编辑区上方浮现一条工具条：「格式化 JSON」「校验」「树状查看」三个按钮；树状查看用可折叠的层级视图（展开/收起箭头、键值配色：键蓝色、字符串绿色、数字橙色、布尔紫红）。
7. **搜索**：顶部搜索框，输入即搜；下拉或列表中高亮命中片段（黄色/蓝色高亮底）。
8. **标签/文件夹管理**：侧栏树形目录，文件夹可展开收起；标签用彩色圆点 + 文字胶囊。
9. **回收站**：侧栏底部入口，列表项带「恢复」「彻底删除」操作。
10. **主题切换**：标题栏右上角月亮/太阳图标，点击动画过渡切换深浅主题（两个主题都要完整实现）。
11. **新建笔记**：标题栏「＋」按钮 + 快捷键提示（⌘N / Ctrl+N）；新建后自动进入编辑态并聚焦标题。

## 五、交互与状态

- 标签页：可关闭（×）、可切换；关闭最后一个标签回到空状态。
- 自动保存状态指示：状态栏右侧「已保存 ✓ / 保存中…」文字，绿色圆点表示已保存。
- 字数统计：状态栏左侧「12 字 · 3 行」。
- 全文搜索无结果时的空状态（放大镜图标 + 「未找到与 XX 相关的内容」）。

## 六、技术约束

- 纯 HTML + CSS + 原生 JS（或轻量脚本），**单文件或少量文件**，不依赖构建工具。
- 用真实的中文示例内容填充（笔记标题用中文，正文含 Markdown 标题、列表、代码块、JSON 示例、表格、引用）。
- 可交互：主题切换、标签页切换/关闭、侧栏折叠、编辑/预览模式切换、树状 JSON 展开收起、搜索输入过滤。
- 代码高亮可内嵌一段精简高亮逻辑或引用 CDN（highlight.js），确保离线预览也能看。
- 字体大小、边距、间距必须精细（用 4px 基准网格）。

## 七、质量要求

- 第一眼必须「苹果质感」：留白充足、层次分明、任何元素都不突兀。
- 深浅两套主题都要完整、协调，不能只是反色。
- 鼠标悬停、点击、聚焦三态都要有细腻反馈。
- 中英文混排美观（PingFang SC / Microsoft YaHei 回退）。
