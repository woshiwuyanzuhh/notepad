# 记事本 · 前端设计迭代 v5（在 notepad-redesign.html 上增量修改）

> 目标：在现有 `notepad-redesign.html`（v4）上做**一处增量修改**：笔记卡片的**鼠标悬浮（hover）强调效果**。保持整体视觉风格完全统一，不触碰其他任何功能。

## 需求：卡片 hover 强调效果

**现状**：v4 卡片 hover 仅轻微上移（translateY(-1px)）+ 浅阴影，不够突出。

**要求**（参考市面成熟案例）：
1. **参考案例**（优先模仿这些的尺度与手感）：
   - **Apple.com 产品卡片**：hover 时卡片轻微放大（scale ~1.02-1.03）+ 阴影抬升（卡片像被"拿起"）
   - **Notion / Linear 卡片**：hover 时边框转为强调色、阴影加深、轻微上浮
   - **macOS Dock / Finder**：放大 + 高亮边缘的"聚焦感"
2. **具体效果**（三条同时生效）：
   - **放大**：hover 时卡片 `transform: scale(1.025)`（比现在明显，但不过度——"稍微变大一点"）
   - **阴影抬升**：阴影从当前浅阴影增强为明显抬升感（如 `0 14px 34px rgba(0,0,0,0.14)`，深色主题 `0 14px 34px rgba(0,0,0,0.5)`），卡片像浮在列表上方
   - **边框强调**：边框从 `var(--border-soft)` 变为强调色描边（如苹果蓝 40% 透明度 `color-mix(in oklab, var(--accent) 40%, var(--border))`）
3. **细节要求**：
   - 过渡动画：200ms 左右 `var(--ease-standard)`，平滑不突兀
   - hover 时卡片 `z-index` 提升，避免被相邻卡片/阴影遮挡
   - **与果冻动画互不干扰**：hover 效果是常态（悬停即放大），点击果冻动画是瞬时（点击时弹跳），两者共存
   - 深浅主题都要协调（深色下阴影更重、边框更亮）
   - 选中态（on）卡片 hover 时：保持强调色描边，放大+阴影效果同样适用（可与选中态叠加，如选中蓝描边加粗 + 放大）

## 验收清单

- [ ] hover 卡片放大（scale 1.025）明显可见
- [ ] 阴影抬升有"拿起"感，深色主题适配
- [ ] 边框强调色（或选中态描边加粗）
- [ ] 200ms 平滑过渡，无跳变
- [ ] 与果冻动画共存，互不干扰
- [ ] 深浅主题均协调
