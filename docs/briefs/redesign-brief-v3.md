# 记事本 · 前端设计迭代 v3（在现有设计稿上增量修改）

> 目标：在项目现有的 `notepad-redesign.html`（v2 重设计稿，已完成并通过评审方向）基础上**增量迭代**，只增加 4 项交互设计，**保持整体视觉风格完全统一**（苹果设计语言 + Obsidian/Notion 信息架构，同一套 tokens/间距/圆角/动效曲线）。
> **重要**：直接编辑现有的 `notepad-redesign.html`，不要重建整套界面；所有新元素必须复用现有设计的 token（--bg/--surface/--accent/--radius-*/--motion-* 等）与组件风格。

## 设计原则（优先级）

1. **优先参考市面优秀成熟案例**——每个交互都先找成熟产品的最优做法，借鉴其信息结构、尺寸、反馈方式，**不要凭空发明**：
   - **右键菜单**：参考 Notion 的卡片右键菜单、Obsidian 的文件右键菜单、语雀/飞书文档的文档树右键菜单——小圆角浮层、分组（操作区/颜色区/危险操作区）、图标+文字行、hover 高亮、轻微 popIn 入场动画
   - **卡片颜色系统**：参考 Notion 的标签/封面色、Bear 的笔记颜色、Apple 备忘录的标签色——柔和低饱和色板（淡红/橙/黄/绿/蓝/紫/粉），卡片着色为 25-30% 透明度的柔和底，不是实色块
   - **卡片点击动画**：参考 Apple 系统弹簧动画（spring）与 Notion 卡片按压反馈——果冻式弹性缩放（~0.45s，overshoot 一次后归位），克制不夸张
   - **字数统计**：参考 Notion/语雀/飞书文档的底部状态栏——右下角小号灰色文字"xxx 字"，与保存状态并排
2. **没有合适案例参考的部分**，自己设计时严格沿用现有设计语言（同样的字体、圆角、阴影、动效曲线）

## 四项需求（在 v2 设计稿上新增）

### 1. 笔记列表专属右键菜单（App 逻辑，替代浏览器默认右键）
- **范围**：只有笔记列表区（中间栏）右键弹出菜单；**其余区域右键不出现任何菜单**（标题栏、侧栏、编辑区右键无反应）
- **卡片上右键**：菜单包含——
  - 顶部：笔记标题（小号灰色，截断）
  - 卡片颜色区：7 个柔和色圆点（淡红/橙/黄/绿/蓝/紫/粉）+ 1 个清除（默认）按钮；当前颜色有选中描边
  - 果冻动画开关行：图标 + "果冻动画" + 右侧滑动开关（iOS 风格 switch，开=苹果蓝）
  - 分隔线
  - 星标 / 置顶 / 删除（删除 hover 红色）
- **列表空白处右键**：新建 Markdown 笔记 / 新建文本笔记 / 分隔线 / 刷新
- **视觉**：与 v2 的弹窗（popover）风格一致——白底/深色底、1px 细边框、12px 圆角、大阴影、150ms popIn 动画；菜单 200-220px 宽
- **参考**：Notion 卡片菜单 / Obsidian 文件菜单的布局与分组方式

### 2. 卡片果冻动画
- 点击卡片时：果冻弹性缩放（scale 1 → 0.96 → 1.03 → 0.985 → 1，总时长 ~0.45s，用 Apple 的 cubic-bezier(0.28, 0, 0.22, 1) 或更弹的曲线）
- 默认开启；被"果冻动画开关"关闭的卡片点击时无动画（仅正常选中反馈）
- **参考**：Apple 系统弹簧交互、Notion 卡片按压反馈——Q 弹但不夸张

### 3. 卡片颜色
- 卡片背景色：所选颜色以 ~28% 透明度混合到卡片底（浅色主题见 #FFD9D9 等淡色效果；深色主题同样柔和，不能刺眼）
- 卡片标题/摘要/时间文字保持可读（颜色只做背景氛围，不改变文字色）
- 选中态（on）仍保留苹果蓝描边高亮，与颜色背景共存
- **参考**：Notion 标签色 / Bear 笔记色 / Apple 备忘录标签

### 4. 右下角字数
- 状态栏最右侧（保存状态之前）：小号灰字 `128 字`，随输入实时更新，等宽数字（tabular-nums）
- 无打开笔记时隐藏
- **参考**：Notion/语雀/飞书的底部字数显示

## 交付要求

- 4 项交互全部可操作：右键卡片弹菜单（选色即时上色、开关即时生效）、点击卡片果冻动画、右下角字数随编辑实时变化
