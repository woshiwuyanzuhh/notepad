# 记事本 · 前端设计迭代 v4（在 notepad-redesign.html 上增量修改）

> 目标：继续在项目现有 `notepad-redesign.html`（v3）上增量迭代，**保持整体视觉风格完全统一**（同一套 tokens/组件语言/动效曲线）。直接编辑现有文件，不重建。

## 需求一：修复果冻动画（v3 未生效）

**现状问题**：v3 已实现 `jellyPop()` 与 `@keyframes jelly`，但点击卡片时动画看不到。

**原因分析**：点击卡片后列表重新渲染（renderList 重建卡片 DOM），动画 class 随旧 DOM 一起消失，用户看不到弹跳。

**修复要求**：
- 点击卡片时果冻动画**稳定可见**：参考 Apple 弹簧手感（scale 1→0.96→1.03→0.985→1，450ms）
- 实现方式任选但必须有效：a) 先播动画再延迟更新选中态/打开笔记（动画完成后再 renderList）；b) 更新后在新 DOM 上重放动画；c) 选中态更新不重建卡片 DOM（只切换 class）
- 默认开启，单卡可关闭（v3 的开关逻辑保留）
- 验收：连续点击卡片都能看到弹跳，不会被重渲染吞掉

## 需求二：侧边栏文件夹树显示笔记文件 + 文件右键菜单

**现状**：侧边栏文件夹树只有文件夹节点，展开后没有文件。

**要求**（参考 Obsidian / 语雀的文档树）：
1. **文件夹展开后显示其中的笔记文件条目**：
   - 文件行：文件图标（MD/TXT 用不同图标或小徽章）+ 文件名 + 右侧小字类型（MD/TXT 徽章沿用现有设计）
   - 点击文件行 → 打开该笔记（与卡片点击一致，含果冻动画）
   - 当前打开的笔记文件行高亮（与列表选中一致的强调色）
2. **文件条目右键菜单**（与卡片右键菜单同风格，参考 Obsidian 文件菜单）：
   - 顶部：文件名
   - 重新命名（见需求三）
   - 设置标签（见需求三）
   - 分隔线
   - 卡片颜色色板 + 果冻动画开关（与卡片菜单一致）
   - 分隔线
   - 星标 / 置顶 / 删除

## 需求三：右键菜单新增「重新命名」与「设置标签」（卡片菜单 + 文件菜单都加）

1. **重新命名**：
   - 点击菜单项 → 浮层内出现内联输入框（预填当前文件名，不含扩展名），回车确认、Esc 取消
   - 确认后文件名即时更新（列表 + 侧栏 + 标签页同步），重名时自动加 (2)
   - 参考：Obsidian/Windows 资源管理器的重命名交互
2. **设置标签**：
   - 点击菜单项 → 弹出标签选择面板（浮层，与菜单同风格）：
     - 显示全部已有标签（胶囊样式，勾选状态表示当前笔记已拥有）
     - 点击标签 = 切换该笔记的标签（立即生效）
     - 底部一个输入框：输入新标签名 + 回车 → 创建新标签并应用到当前笔记
   - 参考：Notion 的标签选择器 / Bear 的标签面板

## 需求四：标签栏编辑功能（添加 / 编辑 / 删除标签）

**现状**：侧边栏标签区只展示标签胶囊，不可编辑。

**要求**（参考 Notion/飞书的标签管理）：
1. **添加**：标签区标题行右侧 + 按钮 → 输入新标签名 → 回车创建（空标签自动跳过）
2. **编辑**：标签胶囊 hover 时显示 ✎ 图标（或右键菜单）→ 进入内联编辑（输入框预填原名）→ 回车保存；**改名后所有笔记中的该标签同步更新**
3. **删除**：标签胶囊 hover 时显示 × 图标 → 点击弹出确认（toast 或 confirm 浮层）→ 确认后**从所有笔记中移除该标签**并删除标签本身
4. 交互细节：hover 操作图标用与现有图标按钮一致的样式（小、圆角、hover 灰底）
